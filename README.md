# 多层感知机
## 范数
好的，我们先从第一个主题开始：** L1 和 L2 范数：测量“权重”的工具。**

###  范数是什么？

**范数**（Norm）在深度学习中，是用来衡量模型的**权重向量** $W$ 的“大小”或者“长度”的一种数学方法。我们可以把模型的权重（例如，某一层神经元的连接强度）看作一个高维空间中的向量，范数就是测量这个向量离原点有多远。

使用范数来衡量权重，是为了**控制模型的复杂度**。如果权重太大，模型可能会过度依赖训练数据中的特定特征，导致过拟合。

### 1. 欧几里得距离：L2 范数

L2 范数是最常用的一种，它也被称为**欧几里得范数**（Euclidean Norm），听起来很像我们中学学过的勾股定理。

* **定义：** 将向量中所有元素的平方求和，再开平方。

$$||W||_2 = \sqrt{\sum_{i=1}^{n} w_i^2}$$

* **特点：** L2 范数对特别大的权重给予**很大的惩罚**（因为是平方），它倾向于让模型的所有权重都保持在一个较小的、均匀的范围内。

### 2. 曼哈顿距离：L1 范数

L1 范数也叫做**曼哈顿范数**（Manhattan Norm）或**出租车范数**，因为它像你在城市里走街道一样，只能走直角。

* **定义：** 将向量中所有元素的绝对值求和。

$$||W||_1 = \sum_{i=1}^{n} |w_i|$$

* **特点：** L1 范数倾向于将一些不重要的权重直接变成**零**，使得模型更稀疏（Sparse），相当于帮你“筛选”出真正重要的特征。

## 链式法则
**链式法则**（Chain Rule）是反向传播算法的数学核心，也是最难理解的部分。我们保留公式，但重点解释公式中每个部分**代表的含义**。

我们继续使用上一个简单的例子：

  * **预测值 $A$：** $A = w \cdot x$
  * **误差值 $D$：** $D = A - y$
  * **损失 $L$：** $L = D^2$

### 🎯 目标：计算 $\frac{\partial L}{\partial w}$

我们的目标是找到损失 $L$ 对权重 $w$ 的**梯度** $\frac{\partial L}{\partial w}$，以便知道 $w$ 应该如何调整才能让 $L$ 最小。

#### 步骤 1: 完整的责任链 (The Chain Rule Setup)

损失 $L$ 最终是通过 $D$、然后通过 $A$、最后才通过 $w$ 影响到的。所以，我们需要将影响一步步传导：

$$\frac{\partial L}{\partial w} = \underbrace{\frac{\partial L}{\partial D}}_{\text{第一棒}} \cdot \underbrace{\frac{\partial D}{\partial A}}_{\text{第二棒}} \cdot \underbrace{\frac{\partial A}{\partial w}}_{\text{第三棒}}$$

#### 步骤 2: 责任的传递与量化 (Conceptual Breakdown)

反向传播的精髓就是**将计算总梯度 $\frac{\partial L}{\partial w}$ 的责任，分解给计算图上的每一个局部操作**。

| 公式部分 | 概念意义 (责任量化) | 代数计算 |
| :--- | :--- | :--- |
| **第一棒: $\frac{\partial L}{\partial D}$** | **损失对误差的敏感度。** <br> 它衡量：当误差值 $D$ 发生微小变化时，损失 $L$ 会如何变化？ <br> *（这是反向传播开始计算的第一项）* | $\frac{\partial}{\partial D}(D^2) = \mathbf{2D}$ |
| **第二棒: $\frac{\partial D}{\partial A}$** | **误差对预测值的敏感度。** <br> 它衡量：当预测值 $A$ 发生微小变化时，误差 $D$ 会如何变化？ <br> *（这是将责任继续传给前一个操作）* | $\frac{\partial}{\partial A}(A - y) = \mathbf{1}$ |
| **第三棒: $\frac{\partial A}{\partial w}$** | **权重 $w$ 的局部贡献。** <br> 它衡量：当权重 $w$ 发生微小变化时，预测值 $A$ 会如何变化？ <br> *（这是 $w$ 在局部计算中对结果的直接影响）* | $\frac{\partial}{\partial w}(w \cdot x) = \mathbf{x}$ |

#### 步骤 3: 最终梯度的合成 (The Final Gradient)

我们将所有局部梯度相乘，得到最终的总梯度 $\frac{\partial L}{\partial w}$：

$$\frac{\partial L}{\partial w} = (2D) \cdot (1) \cdot (x)$$

$$\frac{\partial L}{\partial w} = 2D x$$

**概念解释：**

  * $2D$：代表当前的**误差大小**（即惩罚有多重）。
  * $x$：代表权重 $w$ 的**输入值**。
  * **最终结果**：权重 $w$ 的调整方向和幅度，正比于当前的**误差大小**和该权重**在前向传播中接收到的输入**。

这保证了：**误差越大**或**输入 $x$ 越大**，权重 $w$ 需要调整的幅度就越大！

-----

现在，我们把 $\frac{\partial L}{\partial w} = 2D x$ 代回我们学过的**梯度下降更新公式**中：

$$w_{new} = w_{old} - \eta \cdot \frac{\partial L}{\partial w}$$

$$w_{new} = w_{old} - \eta \cdot (2D x)$$

在这个公式中，$\eta \cdot (2D x)$ 指明了**权重 $w$ 应该向哪个方向调整**（正负号）以及**调整多大幅度**（数值大小）。

## 梯度爆炸、梯度消失
你问到了训练深度神经网络中**最常见且最重要**的两个挑战！**梯度消失**和**梯度爆炸**是**反向传播**的直接后果。

回忆我们之前讨论的**链式法则**：$\frac{\partial L}{\partial w}$ 是由许多层的局部梯度连乘得到的。问题的根源就出在这个**连乘**上。

---

### 1. 梯度消失 (Gradient Vanishing) 📉

#### 核心机制：乘法链过小

**梯度消失**是指在反向传播过程中，计算得到的梯度值随着层数往前（靠近输入层）传递，会变得**越来越小，最终趋近于零**。

1.  **根本原因：连乘效应**
    * 在反向传播中，靠近输入层的梯度是**所有后续层局部梯度的连乘**。
    * 如果大部分局部梯度都小于 1（例如 0.2），那么 $0.2 \times 0.2 \times 0.2 \times \dots$ 经过几十层的连乘后，结果会迅速趋近于 $0$。

2.  **历史原因：激活函数**
    * 早期常用的 **Sigmoid** 或 **Tanh** 激活函数在输入值很大或很小时，它们的导数（局部梯度）会变得**非常小**（接近 $0$）。
    * 当这些很小的局部梯度被连乘时，就会导致梯度消失。

3.  **后果：训练停滞**
    * **靠近输入层的权重**（学习最初始特征的层）接收到的梯度接近于 $0$。
    * 根据梯度下降公式 $W_{new} = W_{old} - \eta \cdot \frac{\partial L}{\partial W}$，如果 $\frac{\partial L}{\partial W} \approx 0$，则权重几乎不再更新。
    * **结论：** 浅层权重停止学习，模型只能依赖深层（靠近输出层）的特征，导致训练效果差。

#### 主要解决方案：

* **更换激活函数：** 使用 **ReLU (Rectified Linear Unit)** 激活函数。ReLU 在 $x > 0$ 时的导数恒为 $1$，有效避免了梯度在正值区域的连乘消失。
* **权重初始化：** 使用更优秀的初始化方法（如 **Xavier/Glorot** 或 **Kaiming/He** 初始化），确保初始权重能让前向和反向传播的信号保持合理的方差。
* **特殊网络结构：** 在循环神经网络（RNN）中，使用 **LSTM** 或 **GRU** 等结构来建立特殊的“记忆门”，可以有效地控制信息流，缓解梯度消失。

---

### 2. 梯度爆炸 (Gradient Explosion) 💥

#### 核心机制：乘法链过大

**梯度爆炸**是指在反向传播过程中，梯度值随着层数往前传递，会变得**极其巨大，最终溢出**。

1.  **根本原因：连乘效应**
    * 如果网络中的**权重**（Weight）本身就很大（例如 $> 1.0$），或者网络结构非常不稳定。
    * 在反向传播中，如果局部梯度都大于 $1$（例如 $10$），那么 $10 \times 10 \times 10 \times \dots$ 经过几十层的连乘后，梯度会变得指数级增大。

2.  **后果：模型发散**
    * 权重接收到**巨大**的梯度 $\frac{\partial L}{\partial W}$。
    * 根据梯度下降公式，权重 $W$ 会被更新一个**非常大的幅度**，导致模型一步跨过最优解，并在下一步彻底偏离轨道。
    * **结论：** 损失函数的值变成 `NaN`（Not a Number），模型**彻底崩溃，无法收敛**。

#### 主要解决方案：

* **梯度裁剪 (Gradient Clipping)：** 这是最直接、最常用的方法。在反向传播完成后，检查梯度向量的 L2 范数。如果梯度的范数超过一个预设的阈值，就将梯度等比例地缩小到该阈值。
    * *例如：* 如果设置阈值为 5，算出的梯度范数是 10，则将梯度缩小一半。
* **权重初始化：** 确保初始权重不要太大。
* **减小学习率：** 使用更小的学习率 $\eta$，减小权重更新的步长，防止单次更新幅度过大。
* **批量归一化 (Batch Normalization)：** 通过归一化每层激活值的分布，有效地限制了输入数据的范围，有助于稳定梯度。

## 使用参数初始化打破对称性
这是一个非常棒的问题，因为它涉及到神经网络**能否开始学习**以及**学习的质量**。

**参数初始化**是训练深度学习模型的第一步，它主要解决了两个核心问题：
1.  **打破对称性：** 让网络中的每个神经元都能独立学习不同的特征。
2.  **稳定信号：** 确保梯度和激活值在网络中传递时不会消失或爆炸。

---

### 1. 打破对称性 (Breaking Symmetry)

#### 概念：同质化灾难

想象一下你的神经网络有两个神经元，它们在同一层，接收同样的输入。

如果这两个神经元的**所有权重**都被初始化为**相同的值**（例如，全部初始化为 0 或全部初始化为 1），那么就会发生**对称性问题**。

1.  **前向传播 (Forward Pass)：** 两个神经元接收同样的输入，权重也一样，所以它们的输出 $A_1$ 和 $A_2$ 将永远是**完全一样**的。
2.  **反向传播 (Backward Pass)：** 由于它们的输出一样，在计算损失 $L$ 对它们的梯度 $\frac{\partial L}{\partial W}$ 时，链式法则计算出的梯度值也会**完全一样**。
3.  **权重更新：** 梯度一样，更新的幅度就一样。它们经过 $W_{new} = W_{old} - \eta \cdot \text{Gradient}$ 更新后，权重仍然保持一致。

**后果：** 这两个神经元将永远计算同样的函数，学习同样的特征。你的神经网络无论有多少神经元，在计算上都等同于只有一个神经元，丧失了深度学习捕捉复杂特征的能力。

#### 解决方案：随机初始化 (Random Initialization)

为了**打破对称性**，我们必须确保**每个神经元的权重都是独一无二的**。

* 方法：将权重 $W$ 初始化为从某个**随机分布**中取出的**小数值**。
* 这样，每个神经元从不同的起点开始学习，从而确保它们在反向传播中得到不同的梯度，最终学习到不同的、有用的特征。

---

### 2. 参数的默认初始化 (Naive Initialization)

为了打破对称性，最早期的做法是简单地使用**小随机数**进行初始化（例如从均值为 0、方差为 0.01 的正态分布中抽取）。

* **优点：** 成功打破了对称性。
* **缺点：** 这种初始化方法并没有考虑到网络的深度和宽度，这直接导致了我们之前讨论的**梯度消失或爆炸**问题。

#### 为什么简单的“小随机数”不好？ (信号稳定性问题)

想象一个有 100 层的深层网络：

1.  **前向传播中的信号衰减：** 如果你的初始权重 $W$ 的值都非常小（例如都在 $0.001$ 附近），当数据 $X$ 经过 100 次矩阵乘法时，信号会 $X \cdot W_1 \cdot W_2 \cdot \dots \cdot W_{100}$ 被连续缩小，最终变成一个**极小值**（趋于 0）。这就是**激活值消失**，网络无法学习。
2.  **反向传播中的梯度问题：** 相反，如果你的 $W$ 稍微大一点，每次乘法都让信号放大，那么经过 100 层的连乘，梯度就会**爆炸**。

因此，好的初始化策略必须保证**信号在网络中传输时，其“强度”保持稳定**。

---

### 3. Xavier/Glorot 初始化

**Xavier 初始化**（也称 **Glorot 初始化**）正是为了解决深层网络中**信号稳定问题**而诞生的初始化方法。它得名于其提出者 Xavier Glorot。

#### 核心目标：方差不变性 (Variance Preservation)

Xavier 初始化的数学目标非常明确：**确保网络中每一层输出的方差 (Variance) 都近似于其输入的方差。**

* 如果方差缩小，信息就会消失（梯度消失）。
* 如果方差增大，信息就会爆炸（梯度爆炸）。

为了达到这个目标，Xavier 初始化要求权重的方差与该层的**连接数**相关：

$$\text{Var}(W) = \frac{2}{n_{\text{in}} + n_{\text{out}}}$$

其中：
* $n_{\text{in}}$：该层的**输入连接数**（即上一层神经元的数量）。
* $n_{\text{out}}$：该层的**输出连接数**（即当前层神经元的数量）。

#### 💡 如何使用 (公式的含义)：

Xavier 规定，权重 $W$ 应该从一个**均值为 0**、**方差**为 $\frac{2}{n_{\text{in}} + n_{\text{out}}}$ 的分布中随机抽取。

$$W \sim \mathcal{N} \left( 0, \sqrt{\frac{2}{n_{\text{in}} + n_{\text{out}}}} \right)$$
（通常使用正态分布 $\mathcal{N}$ 或均匀分布 $U$）

**原理分析：**

这个公式的意义在于，它聪明地**平衡**了输入的数量 $n_{\text{in}}$。

* 如果一个神经元有**大量的输入**（$n_{\text{in}}$ 很大），那么为了防止输出方差太大，每个权重 $W$ 就必须设置得**更小**。
* 如果一个神经元只有**少量输入**（$n_{\text{in}}$ 很小），那么每个权重 $W$ 就可以设置得**更大**。

通过这种自适应的初始化，Xavier 极大地改善了早期使用 Sigmoid 或 Tanh 等激活函数的深度神经网络的训练稳定性。

#### He 初始化 (ReLU 的优化)

需要补充的是，Xavier 初始化是针对 Sigmoid 和 Tanh 等激活函数设计的。对于目前最流行的 **ReLU** 激活函数（它会将负值设为 0，相当于**舍弃了一半的神经元**），通常会使用 **He 初始化**（也称 Kaiming 初始化），它将方差调整为：

$$\text{Var}(W) = \frac{2}{n_{\text{in}}}$$

（只考虑输入连接数 $n_{\text{in}}$，因为它认为另一半的神经元已经被 ReLU 关掉了。）

### 总结对比

| 初始化方法 | 优点 | 缺点 | 适用激活函数 |
| :--- | :--- | :--- | :--- |
| **零初始化** | N/A | 导致**对称性问题**，网络无法学习。 | ❌ 任何函数 |
| **小随机数** | 打破对称性。 | 无法保证信号稳定，易导致**梯度消失/爆炸**。 | ❌ 不推荐 |
| **Xavier/Glorot** | 维持信号方差稳定。 | 需要计算 $n_{\text{in}}$ 和 $n_{\text{out}}$。 | ✅ Sigmoid, Tanh |
| **He/Kaiming** | 维持信号方差稳定，针对 ReLU 优化。 | 需要计算 $n_{\text{in}}$。 | ✅ ReLU 及其变体 |

## 分布偏移、环境偏移、非平稳偏移
你提到的**分布偏移**（Distribution Shift）是机器学习模型在实际部署中最常见的失败原因，掌握它对于构建健壮（Robust）的系统至关重要。

**核心问题：** 训练数据 $P_{\text{tr}}(X, Y)$ 的分布与测试/部署数据 $P_{\text{te}}(X, Y)$ 的分布不一致。

---

### 1. 三大核心分布偏移 (The Three Major Shifts)

分布偏移可以分解为以下三个主要类型，它们涉及不同的概率分量的变化：

#### A. 协变量偏移 (Covariate Shift)

* **定义：** **输入数据 $X$ 的分布发生了变化，但 $X$ 到 $Y$ 的映射关系（即条件概率 $P(Y|X)$）保持不变。**
    * $$P_{\text{tr}}(Y|X) = P_{\text{te}}(Y|X) \quad \text{但} \quad P_{\text{tr}}(X) \ne P_{\text{te}}(X)$$
* **本质：** 模型学到的**底层规律仍然适用**，但模型在部署时看到的**输入数据变得陌生**了。
* **例子：** **人脸识别系统在不同光照下使用。**
    * **训练数据 $P_{\text{tr}}(X)$：** 大部分是在晴朗白天下拍摄的清晰人脸图片（输入 $X$）。
    * **部署数据 $P_{\text{te}}(X)$：** 部署后，系统开始处理很多阴天或夜间低光照的人脸图片。
    * **关系 $P(Y|X)$：** 识别“张三”的特征（例如五官结构）并没有变，模型依然知道如何识别张三，但由于输入图片（X）的光照条件变了，导致识别难度增加。

#### B. 概念偏移 (Concept Shift)

* **定义：** **输入数据 $X$ 的分布保持不变，但 $X$ 到 $Y$ 的映射关系（即概念 $P(Y|X)$）发生了变化。**
    * $$P_{\text{tr}}(X) = P_{\text{te}}(X) \quad \text{但} \quad P_{\text{tr}}(Y|X) \ne P_{\text{te}}(Y|X)$$
* **本质：** 模型看到的**数据（输入 $X$）和以前一样**，但**数据背后的规律或规则变了**。
* **例子：** **预测电商用户点击的意愿。**
    * **输入 $X$：** 用户的年龄、收入、浏览时长等**没有变化**。
    * **关系 $P(Y|X)$：** 在大促（如双十一）之前，用户对一件商品（输入 $X$）的点击意愿（输出 $Y$）会大大**提高**。在活动结束后，意愿又会**降低**。
    * **结论：** 同样的输入 $X$，在不同的时间点代表了不同的用户意愿 $Y$。模型学到的概念过时了。

#### C. 标签偏移 (Label Shift)

* **定义：** **标签 $Y$ 的分布发生了变化，但 $Y$ 到 $X$ 的映射关系（即 $P(X|Y)$）保持不变。**
    * $$P_{\text{tr}}(X|Y) = P_{\text{te}}(X|Y) \quad \text{但} \quad P_{\text{tr}}(Y) \ne P_{\text{te}}(Y)$$
* **本质：** 各个**类别的频率**发生了变化，但每个类别本身的特征没有变。
* **例子：** **股票市场的情感分析。**
    * **训练数据 $P_{\text{tr}}(Y)$：** 训练时，市场情绪中“积极”和“消极”的比例大致各占 50%。
    * **部署数据 $P_{\text{te}}(Y)$：** 部署时恰逢牛市，市场情绪中 90% 的评论都是“积极”的。
    * **关系 $P(X|Y)$：** “积极”评论（标签 $Y$）的措辞和内容（输入 $X$）特征没变，但它在总体中的**出现频率**（标签分布 $P(Y)$）变了。

---

### 2. 环境偏移与非平稳偏移 (Contextual Shifts)

* **环境偏移 (Environmental Shift)：** 这是一个更宏观的术语，指由**外部环境因素**变化引起的任何分布偏移。
    * **例子：** 传感器老化导致数据输入（$X$）带有更大的噪声（导致**协变量偏移**）。新法规出台导致用户行为习惯改变（导致**概念偏移**）。
* **非平稳偏移 (Non-stationary Shift)：** 指分布偏移是**随时间持续发生**或周期性发生的。
    * **例子：** 季节性变化导致服装推荐的趋势改变（周期性**概念偏移**）。或者，模型本身对用户产生影响，导致用户行为在模型部署后发生改变（持续性的**协变量偏移**）。

---
### 分布偏移的纠正方法
#### A. 纠正协变量偏移：重要性加权 (Importance Weighting)

* **目标：** 当**输入分布 $P(X)$ 变化**，但底层规律 $P(Y|X)$ 不变时。
* **核心思路：** 通过数学方法重新分配训练样本的权重，使得训练集在统计上更接近目标测试集。
* **详细机制：**
    1.  **计算权重 $\beta_i$：** 对训练集中的每个样本 $X_i$，计算其权重 $\beta_i = \frac{P_{\text{te}}(X_i)}{P_{\text{tr}}(X_i)}$。
    2.  **权重含义：** 如果一个样本在目标域（部署环境）中很常见，但在训练集里很少见，那么它的 $\beta_i$ 就会很高，训练时模型就会**更重视**它。
    3.  **损失函数：** 在梯度下降时，损失函数变为 $\text{Loss}_{\text{weighted}} = \sum \beta_i \cdot L(X_i, Y_i)$。
* **挑战：** 难以准确估计 $P_{\text{te}}(X)$ 和 $P_{\text{tr}}(X)$ 这两个概率密度函数。

---

#### B. 纠正概念偏移：持续学习与在线学习 (Continual / Online Learning)

* **目标：** 当**底层规律 $P(Y|X)$ 随时间变化**时（即概念过时）。
* **核心思路：** 模型需要动态、快速地吸收新知识，并遗忘或调整旧知识。
* **详细机制：**
    1.  **漂移检测：** 首先，需要一个机制来**检测** $P(Y|X)$ 是否发生了显著变化（例如，监控模型的预测误差是否突然增大）。
    2.  **在线/增量学习 (Online/Incremental Learning)：** 模型不是一次性训练完成的，而是接收到新数据后就立即或频繁地进行小幅度的权重更新。这使得模型能够实时捕捉最新的概念变化。
    3.  **遗忘机制：** 在持续学习中，一个重要的挑战是**灾难性遗忘**（Catastrophic Forgetting）。即模型在学习新概念时，会忘记之前学到的旧概念。因此，需要特殊的正则化方法或记忆回放机制来保持旧知识。
* **例子：** 信用卡诈骗检测模型需要不断适应诈骗者最新的作案手法。

---

#### C. 纠正标签偏移：标签频率调整 (Label Frequency Adjustment)

* **目标：** 当**标签分布 $P(Y)$ 变化**，但 $P(X|Y)$ 不变时。
* **核心思路：** 估算目标域的标签频率 $P_{\text{te}}(Y)$，并用它来修正模型的最终输出。
* **详细机制：**
    1.  **估计 $P_{\text{te}}(Y)$：** 使用统计方法（如期望最大化 EM 算法）来估计目标测试集中每个类别的实际频率。
    2.  **后处理修正 (Post-processing Correction)：** 训练一个分类器 $f(X)$，它的输出 $\hat{Y}$ 应该满足：$\sum_{X} f(X) P_{\text{te}}(X) = P_{\text{te}}(Y)$。但由于 $P_{\text{te}}(Y)$ 变化了，我们需要调整分类器输出的概率，使其聚合后的频率与新的 $P_{\text{te}}(Y)$ 匹配。
    3.  **简单理解：** 如果你发现“积极”标签的出现频率从 50% 变到 90%，模型需要将一部分原本可能被判定为“中性”或“消极”的预测调整为“积极”，以反映新的群体趋势。
* **挑战：** 这种方法要求 $P(X|Y)$ 必须严格保持不变，但在实际中很难保证。

---

#### D. 普适方法：领域适应与特征不变性 (Domain Adaptation & Generalization)

* **目标：** 应对各种复杂的分布偏移，尤其是**同时存在**协变量偏移和轻微的概念偏移时。
* **核心思路：** 训练模型去学习**与域信息无关**（Domain-Invariant）的特征。
* **详细机制：**
    1.  **特征提取器 $G_f$：** 负责从原始输入 $X$ 中提取用于任务的核心特征 $Z$。
    2.  **域鉴别器 $G_d$：** 负责判断 $Z$ 是来自训练集（源域）还是测试集（目标域）。
    3.  **对抗性训练 (Adversarial Training)：** $G_f$ 努力最大化任务准确率的同时，努力最小化 $G_d$ 的分类能力（即 $G_f$ 努力“欺骗” $G_d$）。
    4.  **结果：** 当 $G_d$ 无法区分 $Z$ 的来源时，特征 $Z$ 就是**域无关的**。这意味着模型学到了数据的**本质规律**，不会受到外部环境变化（如光照、背景风格）的影响。

---

这四种方法分别针对分布偏移的不同数学根源。其中，**持续学习**和**领域适应**是目前处理实际应用中复杂、实时漂移的两大研究热点。
## 学习问题的分类法
你提出的这个分类法实际上涵盖了机器学习从**静态数据处理**到**动态环境交互**的演变过程。掌握这个框架，能帮助你理解不同类型的学习算法适用于哪种业务场景。

我们将这些概念分为三个主要层次：

### 层次一：静态数据与预测 (Static Data & Prediction)

这部分关注从固定数据集到预测结果的学习。

#### 1. 批量学习 (Batch Learning)

* **定义：** 一次性地使用**所有**可用的训练数据进行模型训练。
* **特点：** 训练完成后，模型参数固定，不会在实时环境中根据新数据立即更新。它通常用于**离线训练**。
* **优势：** 训练稳定，效率高（可以利用并行计算）。
* **劣势：** 无法应对**非平稳偏移**（即数据分布随时间变化）。
* **应用：** 图像分类、文本情感分析等大多数传统的机器学习任务。

#### 2. 分类学习 (Classification Learning)

* **定义：** 预测输出是一个**离散的类别标签**（如 A 类、B 类、垃圾邮件、非垃圾邮件）。
* **与批量学习关系：** 分类学习是一种**目标**，而批量学习是一种**数据处理模式**。通常，分类学习是采用批量学习模式进行训练的。
* **应用：** 垃圾邮件过滤、疾病诊断（有/无）、物体识别。

---

### 层次二：交互式学习的起点 (The Start of Interactive Learning)

这部分关注代理 (Agent) 开始与环境进行简单的交互。

#### 3. 老虎机 (Multi-Armed Bandit, MAB)

* **定义：** MAB 是最简单的**交互式学习**问题，它模拟了在多个选择中（多个“摇臂”）选择收益最大的那个。
* **核心挑战：** **探索与利用 (Exploration vs. Exploitation)**
    * **探索：** 尝试新的摇臂，找出潜在的更高收益。
    * **利用：** 选择目前已知收益最高的摇臂，以最大化当前回报。
* **MAB 的特点：** MAB 问题是**无状态**的。即你摇动哪个摇臂，不会影响你下次摇臂时的潜在收益（即环境状态不依赖于你的动作）。
* **应用：** 互联网广告推荐（在多个广告位中选择点击率最高的那个）、临床试验中的药物选择。

---

### 层次三：复杂交互与反馈 (Complex Interaction & Feedback)

这部分关注代理在复杂、动态环境中进行一系列的决策。

#### 4. 考虑到环境 (Considering the Environment)

* **定义：** 这是 Control 和 RL 的必要前提。这意味着**代理的行动会改变环境的状态**，进而影响代理未来的观察和回报。学习过程是一个**反馈循环**。
* **例子：** 自动驾驶汽车打方向盘（行动）会改变车辆在道路上的位置（环境状态），影响它下一步的决策。

#### 5. 控制 (Control)

* **定义：** 目标是找到一系列行动，使得系统从当前状态到达**预定的目标状态**（如将机器人从 A 点移动到 B 点）。
* **特点：** 在经典控制理论中，环境的状态和行动的结果通常是**确定的**或可以被精确建模的（例如简单的物理定律）。重点在于**规划和最优路径的计算**。
* **应用：** 机器人路径规划、PID 控制器、航空航天领域的精确导航。

#### 6. 强化学习 (Reinforcement Learning, RL)

* **定义：** RL 是一个通用的框架，用于解决**序贯决策问题**（Sequential Decision Making）。代理通过与**不确定**的环境进行交互，学习如何做出行动来最大化**累积回报**（而非即时回报）。
* **核心特点：**
    * **延迟回报 (Delayed Reward)：** 今天的行动可能要到很久以后才能看到收益（例如，围棋中一步棋的好坏要到终局才能体现）。
    * **有状态 (State Space)：** 代理的行动会改变环境状态，影响未来的决策。
* **RL 与 Control 的区别：** RL 通常用于解决环境**不确定**、**状态空间巨大**、**模型未知**的问题，它通过**试错**的方式来学习最优策略。而 Control 强调已知模型的精确规划。
* **应用：** AlphaGo/AlphaStar、复杂机器人控制、金融交易策略。

---

### 总结对比

| 特征 | 批量学习 (Batch) | 老虎机 (MAB) | 强化学习 (RL) |
| :--- | :--- | :--- | :--- |
| **数据模式** | 静态，离线 | 实时交互 | 实时交互 |
| **核心挑战** | 拟合准确性 | 探索与利用 | 延迟回报下的序贯决策 |
| **状态/环境** | 无交互/无状态 | 无状态 | **有状态**，环境改变 |

# 卷积神经网络（CNN）
## 从全连接到卷积
### 1. 核心思想转变
**为什么图像处理不用传统的全连接神经网络 (Fully Connected Network)?**
* **全连接的局限**：将图像拉平成一长串向量，丢失了像素之间的**空间关系**（比如眼睛是在鼻子上面的）。且参数量巨大，计算极其低效。
* **卷积的突破**：
    1.  **局部感知 (Local Perception)**：像人的视野一样，每次只看图像的一小块区域。
    2.  **权值共享 (Weight Sharing)**：同一个卷积核（特征提取器）在整张图上滑动，用同样的“标准”去寻找特征（比如到处找“垂直边缘”）。

---

### 2. 卷积操作的本质

#### 2.1 什么是卷积？
* **直观定义**：一个小的矩阵（**卷积核 Kernel / Filter**）在大的图像上**滑动**。
* **计算方式**：**对应位置相乘，最后求和**。
    * $Output = \sum (Input \times Weight)$
* **物理意义**：**模式匹配**。
    * 卷积核就是一个“模版”或“指纹”。
    * 如果图像局部与卷积核长得像，输出值就**大**（激活）。
    * 如果完全不像，输出值就**小**（抑制）。

#### 2.2 数学定义 vs. 深度学习定义
连续函数卷积：$$(f * g)(\mathbf{x}) = \int f(\mathbf{z})g(\mathbf{x} - \mathbf{z})d\mathbf{z}. \quad $$
离散数列卷积：$$(f * g)(i) = \sum_{a} f(a)g(i - a). \quad $$
* **数学上的卷积**：公式中包含 $g(x-z)$，意味着卷积核需要**旋转/翻转 180度**。
* **文字解释**： 将一个函数 $g$ 翻转后，再平移 $\mathbf{x}$，然后与 $f$ 相乘并积分。它测量了两个函数重叠的程度。
* 因为计算机处理的是离散的像素值（整数索引 $i$），所以积分就变成了求和 $\sum$。$f$ 和 $g$ s在这里可以看作是一维的数列或信号。**注意**：在标准的数学卷积中，第二个函数 $g$ 仍然是被翻转的（即 $g(i-a)$，而不是 $g(a-i)$）。
* **CNN 中的卷积**：实际上是**互相关运算 (Cross-Correlation)**。
  $$(I \star K)(i, j) = \sum_{a} \sum_{b} I(i+a, j+b) \cdot K(a, b)$$
  * $I(i+a, j+b)$：图像上当前位置 $(i, j)$ 周围的像素值。
  * $K(a, b)$：卷积核上的权重值。
    * **不翻转卷积核**。
    * **原因**：因为卷积核的权重是**学习**出来的。如果特征需要翻转，网络自己会学出一个“翻转后”的权重矩阵。为了计算方便，框架中统一定义为不翻转。

---

### 3. 维度与通道 (Channels) —— 难点突破

图像是三维的（高 $H$、宽 $W$、通道 $C$）。

#### 3.1 卷积核的维度
如果输入是 RGB 图像 ($C_{in}=3$)：
* **卷积核也是三维的**！它必须贯穿输入的所有通道。
* **单个卷积核尺寸**：$k \times k \times C_{in}$ (例如 $3 \times 3 \times 3$)。
* **计算过程**：在 R、G、B 三个通道上分别做二维卷积，然后将三个结果**相加**，得到**一张**二维特征图H。

#### 3.2 多个卷积核 (Filters)
$$H[i, j, d] = \sum_{a} \sum_{b} \sum_{c} V[a, b, c, d]X[i+a, j+b, c]. \quad (6.1.7)$$
  * **目的**：一个卷积核只能提取一种特征（如垂直边缘）。为了看懂图像，我们需要提取多种特征（水平边缘、颜色、纹理等）。
  
这个公式看起来很复杂，但我们把它拆解成四个部分：
| 部分 | 含义 | 解释 |
| :--- | :--- | :--- |
| **$H[i, j, d]$** | **输出特征图** | $H$ 是卷积后的输出。它有**四个**索引：$(i, j)$ 是位置，**$d$ 是“输出通道”的索引**（下一条解释）。 |
| **$\sum_{a} \sum_{b} \sum_{c}$** | **三次求和** | $a$ 和 $b$ 是卷积核的高和宽。**$c$ 是输入通道的求和**（R、G、B）。这是核心。 |
| **$V[a, b, c, d]$** | **卷积核** | $V$ 是**四维的**！$(a, b)$ 是核的位置，$c$ 是核对应的**输入通道**（如 R），**$d$ 是核对应的**输出通道****。 |
| **$X[i+a, j+b, c]$** | **输入图像** | $X$ 是三维输入。$(i+a, j+b)$ 是图像上的局部位置，$c$ 是**输入通道**（如 G）。 |
* $d$ 索引：代表第 $d$ 个卷积核。
* $V[\dots, d]$：代表第 $d$ 个卷积核的权重。
* $H[\dots, d]$：代表第 $d$ 个卷积核产生的第 $d$ 个特征图。

* 输出通道数 ($C_{out}$)：取决于你用了多少个卷积核。
* 
    所以，如果我们使用了 16 个卷积核，那么输出 $H$ 就有 $16$ 个通道，我们称之为特征图通道 (Feature Maps)。
    $$\text{输入} (1024 \times 1024 \times \mathbf{3}) \xrightarrow{\text{16 个 } 3 \times 3 \times \mathbf{3} \text{ 卷积核}} \text{输出} (1022 \times 1022 \times \mathbf{16})$$
---

### 4. 特征图尺寸计算

卷积后，图像尺寸通常会变小。我们可以通过公式精确计算。

#### 4.1 关键参数
* **$W_{in}$**: 输入尺寸
* **$K$**: 卷积核大小 (Kernel Size)
* **$S$**: 步幅 (Stride, 滑动的步长)
* **$P$**: 零填充 (Padding, 边缘补 0 的层数)

#### 4.2 计算公式
$$
W_{out} = \frac{W_{in} - K + 2P}{S} + 1
$$

* **为什么要 Padding ($P$)?**
    1.  **保持尺寸**：抵消卷积带来的尺寸缩小。
    2.  **利用边缘**：增加边缘像素被卷积核覆盖的次数，防止边缘信息丢失。

---

### 5. CNN 是如何“理解”图像的？

#### 5.1 特征抽象金字塔
CNN 通过层层堆叠，将简单的像素转化为抽象的概念：
1.  **浅层 (Low-level)**：卷积核提取**边缘、线条、颜色斑点**。
2.  **激活 (ReLU)**：引入**非线性**。如果没有它，多少层卷积都等于一层线性变换。它允许网络组合特征。
3.  **中层 (Mid-level)**：将边缘组合成**形状**（圆形、方形）、**部件**（眼睛、轮胎）。
4.  **深层 (High-level)**：将部件组合成**完整物体**（人脸、猫、汽车）。

#### 5.2 训练机制 (反向传播)
* **目标**：最小化预测结果与真实结果的误差 (Loss)。
* **梯度 (Gradient)**：误差下降最快的方向。
* **学习率 (Learning Rate)**：沿着梯度方向每一步走多远。
* **更新权重**：
    $$Weight_{new} = Weight_{old} - (LearningRate \times Gradient)$$
    * 通过成千上万次迭代，卷积核从随机的“乱码”变成了能够精准提取特征的“模版”。

## 图像卷积

### 1\. 核心概念：卷积与互相关

在深度学习（如 PyTorch）中，我们常说的“卷积层”实际上执行的是**互相关运算 (Cross-Correlation)**。

  * **操作原理**：

    卷积核（Kernel）作为一个“窗口”在输入图像上滑动。在每个位置，将核与对应的图像像素进行**按元素相乘并求和**。

  * **数学本质**：这是一个**线性变换**。

  * **公式**：
    $$Y = X \star K + b$$
    其中 $X$ 是输入，$K$ 是卷积核权重，$b$ 是标量偏置。

-----

### 2\. 两个关键的可学习参数

#### 2.1 卷积核权重 (Kernel Weights, $K$)

  * **作用**：**特征提取器**。它决定了网络“看”到了什么。
  * **例子**：$K=[1, -1]$ 是一个垂直边缘检测器。它寻找左右像素差异大的地方。
  * **训练目标**：通过梯度下降，从随机数变成能有效提取特征的模式。

#### 2.2 标量偏置 (Scalar Bias, $b$)

  * **作用**：**调整阈值或平移**。它给特征图加上一个固定的数值。
  * **为什么需要它？**：如果目标特征图的整体数值普遍偏大（不以 0 为中心），偏置项负责去“够”到这个基准线。
      * 如果目标 $Y$ 的均值是 0，$b$ 会趋于 0。
      * 如果目标 $Y$ 的均值是 10，$b$ 会趋于 10。

-----

### 3\. 代码实战：训练一个带偏置的卷积层

**实验目标**：让机器自己学会检测“垂直边缘”，并且学会将结果整体“抬高”10 个单位。

####  完整代码 (PyTorch 实现)

```python
import torch
from torch import nn

# 1. 定义互相关运算函数 (用于生成标准答案)
def corr2d(X, K):
    """计算二维互相关运算"""
    h, w = K.shape
    # 输出的高度和宽度计算公式：H_out = H_in - H_k + 1
    Y = torch.zeros((X.shape[0] - h + 1, X.shape[1] - w + 1))
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            # 核心操作：窗口内相乘并求和
            Y[i, j] = (X[i:i + h, j:j + w] * K).sum()
    return Y

# 2. 构造数据 (Data Preparation)
# 构造一个 6x8 的图像，中间有垂直边缘
X = torch.ones((6, 8))
X[:, 2:6] = 0#让2-6格是0，其余是1

# 定义我们要模仿的“真理”卷积核 (检测垂直边缘)
K_target = torch.tensor([[1.0, -1.0]])

# 3. 生成带偏置的标准答案 (Ground Truth)
# 先算标准的边缘检测结果
Y_base = corr2d(X, K_target)
# 【关键点】：人为给目标加上 10 的偏置
TARGET_BIAS = 10.0
Y_prime = Y_base + TARGET_BIAS 

# 4. 构造模型 (Model Setup)
# 输入通道1，输出通道1，核大小(1, 2)，开启偏置 bias=True
conv2d = nn.Conv2d(1, 1, kernel_size=(1, 2), bias=True)

# 5. 调整维度 (Reshape)
# PyTorch 要求输入格式为：(批量大小, 通道数, 高度, 宽度)
X = X.reshape((1, 1, 6, 8))
Y_prime = Y_prime.reshape((1, 1, 6, 7))

# 6. 训练循环 (Training Loop)
lr = 1e-2  # 学习率 0.01 (调整合适以避免梯度爆炸)

print("开始训练...\n")
for i in range(10):
    # --- 前向传播 ---
    Y_hat = conv2d(X)
    
    # --- 计算损失 (MSE) ---
    l = (Y_hat - Y_prime) ** 2
    
    # --- 梯度清零 ---
    conv2d.zero_grad()
    
    # --- 反向传播 ---
    l.sum().backward()
    
    # --- 权重更新 (梯度下降) ---
    # W_new = W_old - lr * gradient
    conv2d.weight.data[:] -= lr * conv2d.weight.grad
    conv2d.bias.data[:] -= lr * conv2d.bias.grad # 同时更新 bias
    
    # --- 打印进度 ---
    if (i + 1) % 2 == 0:
        # 为了输出好看，把 tensor reshape 成 (1, 2)
        current_weight = conv2d.weight.data.reshape((1, 2))
        current_bias = conv2d.bias.data.item()
        print(f'epoch {i+1}, loss {l.sum():.3f}')
        print(f'  Current Weight: {current_weight}')
        print(f'  Current Bias: {current_bias:.4f}')
```
-----

### 4\. 代码深度解析

#### 4.1 数据维度的 Reshape

```python
X = X.reshape((1, 1, 6, 8))
```

PyTorch 处理的是**四维张量**。即使只有一张黑白图，也必须写成 `(1, 1, 6, 8)`。

  * 第 1 个 1：Batch Size（一批处理几张图）。
  * 第 2 个 1：Channels（通道数，RGB 就是 3，黑白是 1）。

#### 4.2 损失函数的选择

```python
l = (Y_hat - Y_prime) ** 2
```

这是 **均方误差 (MSE)**。它衡量了“预测值”和“带偏置的真实值”之间的距离平方。平方是为了放大误差，让模型对大错误更敏感。

#### 4.3 为什么 Bias 收敛到 10？

代码中我们设置了 `Y_prime = Y_base + 10.0`。

  * `Y_base` 的均值接近 0。
  * `Y_prime` 的均值接近 10。
  * 模型公式是 $X \star K + b$。为了让等式成立，梯度下降会自动驱使 $b$ 去拟合那个 10 的差距。

-----

### 5\. 实验结果分析

运行上述代码（学习率 `1e-2`），我们得到：

```text
epoch 10, loss 8.400
  Current Weight: tensor([[ 1.2251, -0.4261]])
  Current Bias: 9.5527
```

1.  **Bias (偏置)**：迅速从随机值增长到了 **9.55**，非常接近目标的 **10.0**。证明模型学会了整体平移特征图。
2.  **Weight (权重)**：正在慢慢向 **$[1.0, -1.0]$** 靠近。
      * *注*：权重没有立刻变成完美 $[1, -1]$ 的原因是：Bias 在早期增长太快，帮模型分担了很多“降低 Loss”的任务，导致权重的更新压力变小了。继续训练更多轮次，它们都会完美收敛。

### 6\. 总结 (Takeaway)

  * **卷积层不只是卷积核**：它由**权重 ($K$)** 和 **偏置 ($b$)** 共同组成。
  * **各司其职**：
      * **权重**负责捕捉**局部形状**（如边缘）。
      * **偏置**负责调整**整体水平**（如亮度、基准值）。
  * **监督学习**：只要有正确的输入 ($X$) 和目标 ($Y$)，反向传播算法就能自动把这两个参数调整到最佳值。
## 填充和步幅
### 1\. 背景：为什么需要它们？

在标准的卷积操作中，如果没有任何干预，我们会面临两个主要问题：

1.  **尺寸减小 (Shrinking Output)**：随着卷积层数的增加，输出特征图的尺寸会越来越小（比如 $8 \times 8 \to 6 \times 6 \to 4 \times 4$），导致深层网络无法构建，信息丢失。
2.  **边缘信息丢失 (Edge Information Loss)**：图像角落和边缘的像素被卷积核覆盖的次数远少于中心像素，导致边缘特征无法被有效提取。

**解决方案**：

  * **填充 (Padding)**：解决尺寸减小和边缘丢失问题。
  * **步幅 (Stride)**：解决计算量过大问题，用于降采样（减小尺寸）。

-----

### 2\. 核心概念与参数

#### 2.1 填充 (Padding, $p$)

  * **定义**：在输入图像的边界周围添加额外的行/列（通常填充数值 0）。
  * **运算顺序**：**先填充，后卷积**。先改变输入的“地盘”大小，再让核在上面跑。
  * **设置技巧**：
      * 为了使 **输出尺寸 = 输入尺寸**，通常取 $p = k - 1$（总填充量）。
      * 若卷积核 $k$ 为奇数（如 3, 5），则单侧填充（PyTorch参数）为 $p/2 = (k-1)/2$。
      * *例*：$k=3$，则四周各填 1 圈 ($padding=1$)。

#### 2.2 步幅 (Stride, $s$)

 * **定义**：卷积核在输入图像上**每次滑动的像素格数**。默认情况下，$s=1$，即每次移动一格。
  * **作用**：
    1.  **降采样（Down-sampling）**：当步幅 $s > 1$ 时，输出尺寸会减小，这类似于**池化层**的作用，可以有效降低计算复杂度。
    2.  **增加感受野**：在深层网络中，大步幅有助于让特征图的每个像素点覆盖原始图像**更大**的区域。
-----

### 3\. 卷积层输出尺寸计算公式 (The Golden Formula)
理解公式 (6.3.2) 是理解这一部分的关键。它决定了经过卷积运算后，特征图的高和宽会变成多少。
$$
\left\lfloor (n_h - k_h + p_h + s_h) / s_h \right\rfloor \times \left\lfloor (n_w - k_w + p_w + s_w) / s_w \right\rfloor
$$

**注**：李沐老师教材中的公式 (6.3.2) 稍有不同，它通常简化了 $p_h$ 和 $p_w$ 的表示（可能指的是单侧填充或总填充）。我们使用标准形式进行讲解。

给定输入大小 $n$，卷积核大小 $k$，总填充量 $p$，步幅 $s$，输出尺寸计算如下：

$$
\text{Output Size} = \left\lfloor \frac{n - k + p + s}{s} \right\rfloor
$$

或者分开写成高度 ($h$) 和宽度 ($w$)：

$$
H_{out} = \left\lfloor \frac{n_h - k_h + p_h + s_h}{s_h} \right\rfloor
$$

$$
W_{out} = \left\lfloor \frac{n_w - k_w + p_w + s_w}{s_w} \right\rfloor
$$

#### 📌 符号解释

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| **$n_h, n_w$** | 输入的高度和宽度 | Input Height and Width。 |
| **$k_h, k_w$** | 卷积核的高度和宽度 | Kernel Height and Width。 |
| **$p_h, p_w$** | **总填充量** | 顶部+底部填充的总和，左侧+右侧填充的总和。 |
| **$s_h, s_w$** | 垂直和水平的**步幅** | Stride。 |
| **$\lfloor \cdot \rfloor$** | **向下取整** | 确保输出尺寸是整数。 |
> **💡 公式解读**：
> 我们以高度为例，目标是计算卷积核能从上到下**完整滑动**多少次：
> 1.  **有效输入尺寸**：$n_h + p_h$（输入高度 + 上下填充）。
> 2.  **减去核的尺寸**：$(n_h + p_h) - k_h$。这是从起点到卷积核**最后一次能完整覆盖**的位置所需的空间。
> 3.  **除以步幅**：$\frac{(n_h + p_h) - k_h}{s_h}$。计算在有效空间内，以 $s_h$ 为步长，能滑动多少次。
> 4.  **加上起始位**：因为第一次滑动也算一次输出，所以要**加 1**。

-----

### 4\. PyTorch 代码实战

在 PyTorch 中，`nn.Conv2d` 的参数对应关系：

  * `padding`：指**单侧**填充量（比如 `padding=1` 意味着上下各加 1，总 $p_h=2$）。
  * `stride`：步幅。

#### 4.1 案例一：降采样 (减半)

**场景**：输入 $4 \times 4$，使用 $3 \times 3$ 核，填充 1，步幅 2。

```python
import torch
from torch import nn

# 定义输入 (Batch=1, Channel=1, H=4, W=4)
X = torch.rand(size=(1, 1, 4, 4))

# 定义卷积层：k=3, p=1, s=2
# padding=1 意味着总填充 p_h = 1+1 = 2
conv2d = nn.Conv2d(1, 1, kernel_size=3, padding=1, stride=2)

# 计算输出形状
# 公式：floor((4 - 3 + 2 + 2) / 2) = floor(5/2) = 2
print(conv2d(X).shape)
# 输出: torch.Size([1, 1, 2, 2])
```

*解释*：尺寸从 $4 \times 4$ 变成了 $2 \times 2$，实现了高宽减半。

#### 4.2 案例二：非对称卷积 (复杂情况)

**场景**：高度和宽度的参数不一致。

  * 高度：$n_h=4, k_h=3, p_h=0, s_h=3$
  * 宽度：$n_w=4, k_w=5, p_w=1(\text{单侧}), s_w=4$ (假设输入足够大以支持此操作，这里沿用教材逻辑)

<!-- end list -->

```python
# 假设输入 X 稍大一点以便演示，例如 6x8
X = torch.rand(size=(1, 1, 6, 8))

# 定义非对称卷积
# padding=(0, 1) -> 高度填0，宽度两边各填1
# stride=(3, 4)  -> 高度走3步，宽度走4步
conv2d = nn.Conv2d(1, 1, kernel_size=(3, 5), padding=(0, 1), stride=(3, 4))

print(conv2d(X).shape)
# 输出: torch.Size([1, 1, 2, 2])
```

*计算验证*：

  * **高**：$\lfloor(6 - 3 + 0 + 3) / 3\rfloor = \lfloor 6/3 \rfloor = 2$
  * **宽**：$\lfloor(8 - 5 + (1\times2) + 4) / 4\rfloor = \lfloor 9/4 \rfloor = 2$

-----

### 5\. 总结

1.  **填充 (Padding)** 是为了保尺寸、保边缘。
2.  **步幅 (Stride)** 是为了降维、减运算。
3.  **公式记忆**：$(\text{Input} - \text{Kernel} + \text{Padding}) / \text{Stride} + 1$。
4.  **执行顺序**：先填充，再根据步幅滑动。
5.  **训练保证**：填充是人工设定的超参数，但它保证了边缘像素能被公平地“训练”到，从而提升模型整体效果。
